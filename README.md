# Library-Management-system
Features
<br>
•	Add Book — Add new books with a unique Book ID, title, and author.
<br>
•	View All Books — Display every book with its current status.
<br>
•	Search Book — Find a book by its ID or title.
<br>
•	Issue Book — Mark a book as issued to a person.
<br>
•	Return Book — Mark an issued book as returned/available.
<br>
•	Delete Book — Remove a book record permanently.
